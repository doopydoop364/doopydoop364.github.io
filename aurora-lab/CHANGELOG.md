# Changelog

## Phase 5.1-alpha.2

- Added per-employee structured memory with attributed source IDs, simulated timestamps, bounded retrieval, commitments, questions, formal review requests, and professional interaction records.
- Added opt-in, bounded Atlas evidence follow-ups on the deterministic corporate scheduler, with cancellation after evidence delivery and idempotent completion.
- Added distinct employee role guidance, an expandable researcher-only memory and conversation viewer, and objective employee activity metrics.
- Extended employee runtime checkpoints to version 2, retaining version 1 conversation migration and the existing conservative recovery rules.
- Added mocked tests and a free two-employee, multi-day demonstration. No live or paid inference is part of automated verification.
